# SBB — The Skin Brand Builder

Immersive two-journey sales website for SBB.

- **Foundation** (`#/foundation`) — for people starting a skincare brand ($1,200 program)
- **Growth** (`#/growth`) — for existing brands improving their store ($899 Shopify Revamp + CRO)

Single self-contained `index.html` — no build step, no dependencies.

## Run locally

```
python3 -m http.server 4173
# open http://localhost:4173
```

## Brand system

- Green `#2D6E30` · Beige `#F3EBDD`
- Editorial serif display (Didot-class) + Avenir/Helvetica body
